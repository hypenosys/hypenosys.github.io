## NOTAS DE VERIFICACIÓN TÉCNICA DE INFRAESTRUCTURA

1. **Gatekeeper Worker Relay (`hypenosys-gatekeeper-v2.axlffcc.workers.dev`):**
   - **Reenvío de Payloads:** **VERIFICADO POR LECTURA DE CÓDIGO**. El Worker actúa como relay transparente leyendo el cuerpo original como texto plano (`const body = await request.text()`) y re-enviándolo directamente en la llamada `fetch(..., { body })` hacia NVIDIA NIM. Por tanto, `chat_template_kwargs` y `reasoning_budget` son re-enviados intactos sin filtrado de campos.
   - **Interpretación de NIM para Nemotron-3 Super:** **NO VERIFICADO** (pendiente de prueba del usuario con API Key real de NVIDIA).
   - **Allowlist CORS de Cloudflare:** **Nota:** `http://localhost:4000` NO forma parte de la allowlist de orígenes autorizados del Worker. Para pruebas locales sin CORS block debe usarse la llamada desde origin de producción (`hypenosys.github.io`) o un cliente fuera del navegador.

3. **Preservación de Firmas en Anthropic Tool Use (`thinking_blocks` / `thinking` con signature):**
   - **Estado:** **NO IMPLEMENTADO** (No requerido).
   - **Razón:** La aplicación Hypenosys Neural Chat no utiliza actualmente la API de Tool Use / Function Calling de Anthropic. Si en el futuro se implementaran tools nativas de Anthropic, los bloques `m.raw` de `thinking` con firma criptográfica deberán re-enviarse de forma estructurada según la especificación de Anthropic.
